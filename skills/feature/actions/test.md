# Test the feature

1. Identify the active spec and work branch. Read the spec's verification cases and referenced rules from `context/project-overview.md`. Discover configured commands in the project README, manifests, and CI.
2. Run existing checks for the affected behavior. Add or update tests on the recorded work branch when required by the spec or standards, or when existing coverage would miss a specific regression. Follow the documentation and edit approval rules in `AGENTS.md`. Cover relevant success, boundary, and failure cases.
3. Use the configured test environments. For a UI change, run the app and exercise the affected flow with the tools available for the target. Follow any additional standards linked in the overview. Record the screen or route, applicable display settings, and observed outcome for the relevant states from the spec.
4. Record the command and result or the manual observation for each goal checked. Check off verified goals and leave blocked or incomplete checks open with the reason in `Notes`.
